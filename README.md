# Miniminic

Miniminic은 보물상자를 클릭해서 아이템을 얻고, 모은 아이템을 합성하며 도감을 채우는 클릭/방치형 웹 게임입니다. 순수 HTML/CSS/JavaScript로 구현되어 별도 빌드 도구 없이 브라우저에서 바로 실행할 수 있습니다.

## 주요 기능

- 보물상자 클릭 또는 Space 키 입력으로 랜덤 아이템 획득
- 10초마다 클릭 가능 횟수 1회 충전, 최대 60회 저장
- 일반, 고급, 희귀, 전설, 신화 5단계 레어도와 총 40개 아이템
- 레어도별 인벤토리 표시
- 같은 레어도 아이템 10개를 사용하는 합성 시스템
- 한 번이라도 획득한 아이템을 기록하는 도감 시스템
- 총 클릭 수, 총 합성 수, 최고 획득 레어도, 도감 달성률 통계
- localStorage 기반 저장과 초기화 기능
- GSAP CDN이 로드된 경우 보물상자와 획득 영역에 가벼운 애니메이션 적용

## 게임 규칙

- 클릭 가능 횟수가 1 이상일 때만 보물상자를 열 수 있습니다.
- 보물상자를 열면 클릭 가능 횟수가 1 감소하고 랜덤 아이템 1개를 얻습니다.
- 드랍 확률은 일반 74.99%, 고급 23.00%, 희귀 1.70%, 전설 0.30%, 신화 0.01%입니다.
- 합성 슬롯은 10칸입니다.
- 첫 번째로 넣은 아이템의 레어도가 합성 기준 레어도가 됩니다.
- 이후에는 같은 레어도의 아이템만 슬롯에 넣을 수 있습니다.
- 슬롯 10칸이 모두 찼을 때 합성할 수 있습니다.
- 신화 등급은 최종 등급이라 합성할 수 없습니다.

## 합성 확률

- 일반 10개 → 일반 80%, 고급 20%
- 고급 10개 → 고급 75%, 희귀 25%
- 희귀 10개 → 희귀 70%, 전설 30%
- 전설 10개 → 전설 99%, 신화 1%

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 실행됩니다.

GSAP는 CDN으로 불러옵니다. CDN을 사용할 수 없는 환경에서도 게임의 핵심 기능은 정상 작동하며, CSS 대체 애니메이션이 적용됩니다.
